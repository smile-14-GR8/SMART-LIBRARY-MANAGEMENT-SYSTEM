# VITyarthi Smart Library Management System - Project Statement

## Problem Statement

Managing library records manually can make it difficult to track books,
students, issued books, and returned books. A simple digital system is
required to organize these operations and provide students and
librarians with an easy way to manage library information.

## Scope of the Project

The project focuses on developing a command-line library management
system using Python. It covers student registration and login, book
searching, book issuing and returning, borrowed-book tracking, and basic
librarian operations.

The current system is an educational prototype and does not use an
external database.

## Target Users

### Students

Students can: - Register with their name and registration number. - Log
in using their registration number. - View available books. - Search for
books. - Issue books. - Return books. - View their borrowed books.

### Librarians

Librarians can: - View all books. - Add books. - Remove available
books. - View registered students. - View issued books.

## High-Level Features

1.  Student registration and login
2.  Book viewing and searching
3.  Book issuing and returning
4.  Borrowed-book tracking
5.  Book addition and removal
6.  Student record viewing
7.  Issued-book monitoring

## Technical Approach

The project is implemented using Python fundamentals including: -
Functions - Lists - Dictionaries - Loops - Conditional statements -
String operations - User input and output - Basic validation and error
handling

## Limitations

-   Data exists only during program execution.
-   No database is currently used.
-   Librarian authentication is not currently implemented.
-   The current prototype is implemented as a single Python file.

## Future Scope

The system can be extended with: - Database storage - Librarian
authentication - Due dates and fine calculation - Book reservation -
Graphical user interface - Reports and analytics - Multiple Python
modules/classes - Automated testing
