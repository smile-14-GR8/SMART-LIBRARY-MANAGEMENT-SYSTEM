# Statement - VITyarthi Smart Library Management System

## Problem Statement

Managing library activities manually can be time-consuming and difficult to organize. Students need a simple way to register, search for books, issue and return books, and check their borrowed books. Librarians also need basic options to manage books and view student and issue information.

The Smart Library Management System is developed to provide these basic library operations through a simple command-line interface using Python.

## Scope

The project covers the basic operations required for a small library management system.

It allows:
- Student registration and login
- Viewing and searching books
- Issuing and returning books
- Viewing borrowed books
- Adding and removing books
- Viewing registered students
- Viewing issued books

The project stores information only while the program is running and does not use an external database or file storage.

## Target Users

### Students
Students can register or log in, view and search books, issue available books, return borrowed books, and view their borrowed books.

### Librarians
Librarians can view all books, add or remove books, view registered students, and view currently issued books.

## High-Level Features

- Student registration using name and registration number
- Student login using registration number
- Book viewing and searching
- Book issue and return
- Borrowed book tracking
- Book addition and removal
- Student information viewing
- Issued book information viewing
- Simple command-line interface

## Project Objective

The main objective of this project is to apply basic Python programming concepts such as functions, lists, dictionaries, loops, conditional statements, and user input to develop a practical library management system.
